# FX_master — 게임 기획 정리 (v0.1)

> **기준 문서는 [팀 기획서](https://claude.ai/artifact/CaZEkQ359TnmqCoWacE831)입니다.** 이 파일은 참고용 사본이라 최신이 아닐 수 있어요.

## 1. 개요
- **장르**: 주식 투자 로그라이크
- **콘셉트**: 주인공이 대출을 받아 그 돈으로 주식에 투자하고, 대출금을 갚으며 성공하는 이야기
- **진행 단위**: 날짜(1일 = 1턴). 1일차부터 시작
- **엔진**: Unity

## 2. 하루 루프 (1일 기준)
| 순서 | 단계 | 내용 |
|---|---|---|
| 1 | 뉴스 탐색 | 그날의 뉴스가 생성되어 공개됨. 뉴스가 그날 그래프에 영향을 줌 |
| 2 | 아이템 사용 | 정보형 아이템 등 "아이템 시간용" 아이템 사용, 투자 결정 |
| 3 | 장 시간 | 그래프가 실시간으로 움직임. "장 시간용" 아이템 사용 가능 |
| 4 | 장 결과 | 수익/손실 정산, 주인공 상태(표정·옷) 갱신, 원하는 만큼 빚 상환 |
| 5 | 아이템 구매 | 다음 날을 위한 아이템 구매 |

## 3. 주가 생성 규칙
- 뉴스가 생성되면 그 뉴스를 기준으로 **그날 그래프가 난수로 생성**된다.
- 그래프는 **뉴스 단계에서 확정**되며, 아이템 시간에 플레이어가 바꿀 수 없다.
  (아이템은 결과를 바꾸는 게 아니라 정보를 주거나 장 중에 대응하는 용도)
- **종목별 일일 등락 한도 고정**: 종목마다 하루 최대 상승률과 최대 하락률이 정해져 있다.
- **이어지는 이벤트**: 뉴스는 여러 날에 걸쳐 이어질 수 있다.
  - 예) 1일차 "계약 성사 임박" → +10% / 2일차 계약 **성공** → 추가 상승, **실패** → 하락

## 4. 정보의 두 종류
| 구분 | 정확도 | 기대 수익 |
|---|---|---|
| 뉴스 | 정확함 | 낮음 (모두 아는 정보) |
| 아이템(정보) | 모호함 | 높음 |

## 5. 아이템
- **아이템 시간용**: 정보 아이템 등 (예: 내일 뉴스 힌트, 루머)
- **장 시간용**: 장 중에 쓰는 아이템 (예: 손절/익절 등)
- 아이템 구매 단계에서 구입

## 6. 투자
- 최대 **4개 종목**에 분산 투자 가능
- **장 중 매매 가능**: 장 시간에 차트를 보며 실시간으로 사고팔 수 있음
- 화폐 단위: **달러($)**

## 7. 대출 · 승패
- 시작할 때 대출을 받고 출발
- **상환 기한 없음** → 빚을 모두 갚으면 승리, 그 전에 파산하면 패배
- 빚과 이자는 **어느 날이든 원하는 만큼** 갚을 수 있음
- 진행 중 **추가 대출** 가능
- **일정 기한마다 이자**가 붙음 (빌린 돈이 늘수록 이자 부담도 커짐)

## 8. 로그라이크 요소
- 매 판 **종목 구성 · 뉴스 흐름**이 랜덤
- 매 판 **상점 아이템**이 랜덤
- 메타 성장, 주인공 특성 선택은 넣지 않음 (현재 기준)

## 9. UI 배치
```
┌─────────────┬──────────────────────────┬──────────┐
│ 종목 선택    │                          │          │
│ (클릭 시     │                          │          │
│  다른 종목)  │       주식 차트 (중앙)    │          │
│             │                          │          │
│             │                          ├──────────┤
│             │                          │ 주인공    │
├─────────────┴──────────────────────────┤ 반신 캠   │
│ 아이템 리스트 (하단)                     │          │
└────────────────────────────────────────┴──────────┘
```
- **왼쪽 위**: 종목 선택 — 누르면 다른 종목 차트로 전환
- **가운데**: 주식 차트
- **아래**: 보유 아이템 리스트
- **오른쪽 아래**: 주인공 반신 캠 — 수익/손실에 따라 **표정·옷**이 바뀜

## 10. 밸런스 초안 (v0.1, 플레이테스트로 조정)

### 10-1. 대출 · 이자
| 항목 | 값 |
|---|---|
| 시작 자금 | 대출 **$10,000** (본인 돈 $0) |
| 상환 | 기한 없음. 매일 장 결과 후 원하는 만큼 상환 |
| 이자 | **7일마다 남은 빚의 5%**가 빚에 더해짐 (7·14·21·28일차) |
| 추가 대출 | 1회 $5,000, **최대 3회**. 받을 때마다 이자율 +2%p (5→7→9→11%) |
| 승리 | 빚을 모두 갚음 → 점수 = 걸린 일수 (적을수록 좋음) |
| 패배 | 자산 $100 미만 + 추가 대출 소진 → 파산 |

> 참고: 갚지 않고 30일이 지나면 $10,000가 약 $12,155가 됨. 일찍 조금씩 갚을수록 이자가 줄어듦.

### 10-2. 장 시간
| 항목 | 값 |
|---|---|
| 장 길이 | 실제 시간 **60초** (0.5초마다 1틱, 총 120틱) |
| 매매 수수료 | 거래금액의 **0.2%** (아무 때나 사고팔기를 막는 용도) |
| 동시 보유 | 최대 4종목 |

### 10-3. 종목
- 한 판에 **8종목** 등장 (전체 20종목 풀에서 랜덤 추첨)
- 종목마다 성향이 있고, **하루 등락 한도는 성향으로 고정**

| 성향 | 하루 등락 한도 | 평소 움직임 | 예시 |
|---|---|---|---|
| 안정형 | ±5% | 작음 | 은행, 통신 |
| 보통형 | ±12% | 중간 | 제조, 유통 |
| 고위험형 | ±25% | 큼 | 바이오, 게임, 코인 관련 |

### 10-4. 뉴스
- 하루 **2~3개** 생성, 각 뉴스는 한 종목을 가리킴
- 뉴스는 **방향이 확실**하지만 폭이 작음: 그 종목 그날 결과에 +1~4% (또는 -1~4%)
- 뉴스가 없는 종목은 한도 안에서 무작위로 움직임
- **연쇄 뉴스**: 1단계 뉴스(예: 계약 임박 +3~10%) → 다음 날 2단계 확정
  - 성공(60%): 추가 상승 +5~15% / 실패(40%): -8~20%
  - 결과는 다음 날 뉴스에서 공개 → 정보 아이템으로 미리 엿볼 수 있음

### 10-5. 아이템
상점은 매일 **랜덤 4개** 진열. 정보 아이템은 "확률 힌트"로 모호함을 표현 (틀릴 수 있음).

**아이템 시간용 (정보)**
| 이름 | 가격 | 효과 |
|---|---|---|
| 찌라시 | $300 | 랜덤 1종목의 오늘 방향 (정확도 65%) |
| 애널리스트 리포트 | $600 | 고른 1종목의 오늘 방향 (정확도 75%) |
| 내부자 메모 | $1,200 | 고른 1종목의 오늘 방향 + 대략적 폭 (정확도 85%) |
| 연쇄 예측 | $800 | 진행 중인 연쇄 뉴스 1개의 성공 여부 (정확도 80%) |

**장 시간용**
| 이름 | 가격 | 효과 |
|---|---|---|
| 손절 예약 | $200 | 지정 종목이 -N% 되면 자동 매도 |
| 익절 예약 | $200 | 지정 종목이 +N% 되면 자동 매도 |
| 슬로우 모션 | $500 | 10초간 차트 속도 절반 |
| 시간 정지 | $900 | 5초간 차트 멈춤 (멈춘 동안 매매 가능) |
| 망원경 | $1,000 | 다음 5초 구간 차트 미리보기 |

### 10-6. 주인공 상태 (반신 캠)
- **옷 = 총 순자산 단계** (현금 + 주식 − 빚, 시작 기준 $0)

| 단계 | 순자산 | 모습 |
|---|---|---|
| 1 파산 직전 | -$5,000 미만 | 늘어난 티셔츠, 퀭한 얼굴 |
| 2 궁핍 | -$5,000 ~ $0 | 낡은 후드티 |
| 3 평범 | $0 ~ $5,000 | 깔끔한 셔츠 |
| 4 여유 | $5,000 ~ $20,000 | 정장 |
| 5 부자 | $20,000 이상 | 명품 정장, 시계 |

- **표정 = 그날 수익률** (장 중 실시간으로 바뀜): 폭락 😱 / 손해 😟 / 보합 😐 / 이득 🙂 / 대박 🤩
